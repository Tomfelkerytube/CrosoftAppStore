# Crosoft Appstore
A simple but powerful batch-based App Store for installing CrosoftTM software.

## Features
- 100% written in `.bat`
- Uses `curl` and PowerShell to install apps
- Built-in update system
- App catalog menu
- Manual installers supported (TermInstV2.0)
- Auto-unzip support

## Included Apps
- DosLan 1.6
- Crosoft Terminal
- Adventures of RUN or DIE
- TermInstV2.0 (manual instructions)
- EnceLant 8.1
- EnceLant 7.1 (16-bit Beta)

## Requirements
- Windows 10/11
- `curl` installed (comes with Windows 10+)
- PowerShell enabled

## How to Use
1. Download `AppStore.bat`
2. Double-click to run it
3. Type `help` to see available commands
4. Select `install` to install apps

## Commands
1. Help    - List Commands
2. Exit    - Exit AppStoreShell
3. install    - List all Avaiable Applications.
- END
